# ビーチバレー ゲーム仕様（プロトタイプ）

イメージ: [`reference/concept-beach.webp`](reference/concept-beach.webp)

## 基本
- スマホ横持ち・Webブラウザ（GitHub Pages）
- 2対2。操作するのは自分（A1）だけ。味方（A2）・相手（B1, B2）はbot
- 見た目は3D（予定: Three.js）、ゲームとしては横から見た2D（x = コート長手方向, y = 高さ）
  - 現在は依存なしの2D表示（`src/render/canvas2d.ts`）で動作。3D表示は後で追加し、2Dはデバッグ表示として残す

## 操作
| 操作 | 動作 |
|---|---|
| タップ | その位置まで走る |
| 長押し / ドラッグ | 指を追いかけて走る |
| フリック（素早いスワイプ） | ボールを打つ（約10フレーム先行入力OK） |
| JUMPボタン | ジャンプ |

フリックの方向:
- **上**: トス／パス（ネット寄りの自陣へ上げる）。3打目なら相手コートへ山なりで返す
- **前（ネット方向）**: 相手コートへ打つ。ジャンプ中でボールがネットより高ければ**スパイク**
- **後ろ**: 自陣の後方へパス
- 強さ（速さ）で狙う深さが変わる

サーブ: 自分がサーバーの時に前へフリック。

## ルール
- ラリーポイント制、15点先取（2点差が必要）
- 1チーム3タッチまで、同じ選手の連続タッチ不可（3打目は自動で相手コートへ）
- コート内に落ちたら落ちた側の失点、アウトは最後に触ったチームの失点
- 得点したチームが次のサーブ。サーブ権が移るたびにチーム内でサーバー交代

## bot
- 弾道を予測して担当者を決め、1打目パス → 2打目トス → 3打目アタック（ネット際ならジャンプスパイク）
- 相手の空いている所を狙う
- 反応の遅れ・狙いの誤差・移動速度で難易度を調整（`src/sim/world.ts` の `DEFAULT_TEAMMATE` / `DEFAULT_OPPONENTS`）
- 速い球（約10m/s超）はレシーブ失敗（空振り／弾く）しやすい

## 主要パラメータ
`src/sim/constants.ts` に集約（ネット高 2.24m、重力、ジャンプ力、打球の滞空時間、リーチなど）。
